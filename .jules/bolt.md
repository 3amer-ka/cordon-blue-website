The Render build failed because the Dashboard settings are overriding the `render.yaml` and `package.json` configurations. The logs explicitly state: "Empty build command; skipping build" followed by "Publish directory build does not exist!". You must go to the Render Dashboard for your service (and its parent service if these are PR previews), navigate to **Settings -> Build & Deploy**, and manually clear the empty Build Command (or set it to `npm run build`), and change the Publish Directory from `build` to `.`.
