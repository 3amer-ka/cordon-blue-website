🧪 [testing improvement description] Add general Exception handling and tests for image processing

🎯 **What:** The `optimize_hotel_resort.py` script was vulnerable to crashing upon encountering unidentifiable or corrupt image files when calling `Image.open()`. This PR adds a general `Exception` handling block to gracefully fail and return `False`.
📊 **Coverage:** A new test suite `test_optimize_hotel_resort.py` was introduced. It covers both the `FileNotFoundError` explicitly, and handles general Exceptions (like `UnidentifiedImageError` simulated by `Exception` inheritance) when opening images. Also verifies the happy path.
✨ **Result:** Test coverage for `optimize_hotel_resort.py` is established. The image optimization script is significantly more robust and immune to crashing from invalid input image formats.
