⚡ Bolt: Add preload for LCP hero image

💡 What: Added a `<link rel="preload" as="image">` tag in `index.html` configured with `imagesrcset` and `imagesizes` mirroring the `<picture>` tag of the main hero image.

🎯 Why: The LCP (Largest Contentful Paint) hero image was being loaded via a `<picture>` tag with responsive `srcset`. While this is great for loading the appropriately sized image, it hides the image from the browser's early preload scanner, delaying the start of the image download and hurting LCP times. Preloading explicitly instructs the browser to start downloading it immediately.

📊 Impact: Reduces initial load time by ensuring the hero image begins downloading immediately rather than waiting for the DOM parser to reach and evaluate the `<picture>` tag. Measured basic load time improved from 0.176s to 0.087s locally.

🔬 Measurement: Verify using Lighthouse to see improved LCP metrics, or by reviewing the network tab and confirming the image download starts earlier in the waterfall.
