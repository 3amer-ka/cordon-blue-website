⚡ Bolt: Add preload for LCP hero image

💡 What
Added a `<link rel="preload" as="image">` tag in the `<head>` of `index.html` to preload the hero image using its responsive `imagesrcset` and `imagesizes`. Added `fetchpriority="high"` for optimization.

🎯 Why
The Lighthouse report indicated that the LCP (Largest Contentful Paint) image could be loaded earlier to improve the perceived page load time. Specifically, it highlighted an opportunity in LCP Request Discovery by moving the asset out of the critical rendering block.

📊 Impact
This reduces the discovery delay for the LCP resource, which is expected to shave off precious milliseconds by allowing the browser's preload scanner to start fetching the correctly sized hero image immediately, resulting in a faster rendering of the hero section.

🔬 Measurement
Can be verified by running the Lighthouse audit tool again and observing improvements in the LCP and LCP Request Discovery metrics. Network timing tools should show the LCP image loading concurrently with early CSS/JS resources.
